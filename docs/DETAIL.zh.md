# 对话截屏

在对话输入框的工具栏增加一个「截屏」按钮。点击后整个桌面直接进入选区模式（不压暗、保持原亮度），拖动框选区域即可。选区在松开鼠标后仍然可以编辑——拖动整体挪位置、拖四角/四边的手柄改大小——确认后才生效。结果保存为 PNG、复制到剪贴板，并作为图片附件插入当前草稿，随你的消息一起发送。

界面按豆包截图工具对齐：黑色细虚线选区、8 个白色圆形手柄、左上角外侧的白底圆角尺寸标签（`宽 * 高`）、选区下方左对齐的白色圆角工具条，主按钮是高亮渐变胶囊。

## 用法

1. 打开一个对话。
2. 点击输入框工具栏里的剪刀/相机「截屏」按钮。
3. 拖动框选要截取的区域；只点一下某个窗口则会选中那个窗口，鼠标悬停时窗口会先用虚线框预览。
4. 微调：在选区内按住拖动可整体移动，拖四角或四边的手柄可改大小。
5. 确认：按 `Enter`、在选区内双击，或点工具条里的「✓ 插入对话」；点「复制」只把图放进剪贴板、不关闭选区（标签会短暂显示「已复制」）；点「取消」或按 `Esc` 放弃。
6. 截图会作为附件出现在输入框中；输入你的问题后发送即可。

## 说明

- 仅支持 Windows：截屏通过 Windows PowerShell 与 .NET 屏幕 API 完成。
- 多显示器：选区覆盖整个虚拟桌面，可跨屏拖动截取；坐标按每显示器 DPI 计算，缩放屏也能截到原生像素。
- 最新截图同时复制到剪贴板，方便粘贴到其他地方。
- PNG 只是临时落在 `dsh-screenshot-tool` 目录用于传输字节，读取后即删除，剪贴板保留一份。
- 插件加载时会预热一个常驻 PowerShell 进程（私有内存约 60–80MB），选区界面约 130–220ms 就能出现，不用每次点都重启进程。宿主退出时它自行结束；如果宿主意外消失，它还开着的界面会在 1 秒内自动关闭。
- 若需模型理解图片内容，请使用支持图片输入的模型。
